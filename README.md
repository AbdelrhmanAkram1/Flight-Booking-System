# Flight Booking System

A comprehensive Java-based application designed to manage airline flight schedules, passenger bookings, and payments. The system follows Object-Oriented Programming (OOP) principles and provides a robust framework for handling multi-user interactions and data persistence.

## Key Features

* **Multi-User Roles:** Dedicated interfaces and functionalities for Administrators, Agents, and Customers.
* **Flight Management:** Complete system for scheduling, updating, and tracking flight details.
* **Booking System:** Seamless process for passengers to search for flights and book tickets.
* **Payment Integration:** Module to process and record payment transactions securely.
* **Data Persistence:** Uses a file-based storage system managed via a central `FileManager` to ensure data is saved between sessions.

## Project Structure

* `src/`: Contains all Java source files (e.g., `Flight.java`, `Booking.java`, `Payment.java`, `FileManager.java`, `Administrator.java`).
* `data/`: Directory for persistent storage files (e.g., `flights.txt`, `users.txt`, `bookings.txt`).
